# Backend Engineering

- **FastAPI** — async Python web framework, OpenAPI auto-generation, Pydantic validation
- **REST API design** — resource-oriented routes, proper HTTP semantics, versioned endpoints
- **JWT auth** — stateless authentication, token refresh flow, role-based access control
- **Rate limiting** — token bucket / sliding window per-user throttling via Redis
- **Redis caching** — translation cache layer, session store, rate limit counters
- **SQLAlchemy + Alembic** — async ORM with migration management
- **PostgreSQL** — relational storage for users, usage logs, API keys, translation history
